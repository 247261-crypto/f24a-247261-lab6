Your place and your colour still come from the last digit, in the table at the top of this lab. Digit 0 and digit 3 both build project 0. Digit 0 is Bookshop, navy. Digit 3 is Stationery, teal.

Create the folder f24a-YOURROLL-lab6 and run git init. This is a new folder. Keep it outside lab5. Copy server.js into that folder. Do not change it. Run node server.js. Open the page from http://localhost:3016/.

Open the project on the session bar that matches your remainder. Build that one page. The other two stay on the bar for the class.

The teaching example is one button that loads pen, and one button that sends pen and 2. The three projects are not that button, and they are not the same page as each other.

  • Project 0. Load. The line says Loading…. About one second later the board shows pen 50, copy 80, tea 40. Loaded shows 3. Dearest shows 80. Sum shows 170. Stop the server. Load. The line says The server is not answering. The prices are blank. Loaded, Dearest, and Sum show 0.
  • Project 1. Find pen. The card shows pen and 50. The slip has one row, Times 1. Found shows 1. Dearest shows 50. Find pen again. Times is 2. Find copy. The card shows copy and 80. Found shows 2. Dearest shows 80. Find ruler. The card is blank. The slip stays. Clear the box and Find. The line says undefined.
  • Project 2. Restart the server. Send pen and 2. The ticket shows 1, pen, 100. Count shows 1. Takings shows 100. Send tea and 1. The ticket shows 2, tea, 40. Count shows 2. Takings shows 140. Drop last. The sheet keeps pen. Takings shows 100. The ticket is blank. Send ruler. No new row.
