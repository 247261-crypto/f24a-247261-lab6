30 async returns a promise

async — async on a function means the caller always receives a promise.

async function price() {
  return 50;
}
const receipt = price();
document.querySelector("#kind").textContent = String(receipt);
receipt.then(function (n) {
  document.querySelector("#value").textContent = String(n);
});

You see The kind line is [object Promise]. The value line is 50.

Second look. The caller does not receive 50. The caller receives a promise that will fulfil with 50.

<p id="kind">kind</p>
<p id="value">value</p>
<button id="go" type="button">Go</button>
<script>
async function price() { return 50; }
document.querySelector("#go").addEventListener("click", function () {
  const receipt = price();
  document.querySelector("#kind").textContent = String(receipt);
  receipt.then(function (n) {
    document.querySelector("#value").textContent = String(n);
  });
});
</script>

31 return 50 is still a promise

return — return 50 inside an async function fulfils the promise. It does not hand 50 back as a plain number.

async function price() {
  return 50;
}
const receipt = price();
document.querySelector("#out").textContent = String(receipt + 1);

You see [object Promise]1.

Second look. Adding 1 happens to the promise object. The 50 is inside it. This is the same trap as a missing await.

<p id="out">Ready.</p>
<button id="go" type="button">Go</button>
<script>
document.querySelector("#go").addEventListener("click", async function () {
async function price() {
  return 50;
}
const receipt = price();
document.querySelector("#out").textContent = String(receipt + 1);
});
</script>

32 await parks this function

await — await p pauses this function until p settles. The lines under await run after that.

document.querySelector("#out").textContent = "Waiting";
await new Promise(function (resolve) {
  setTimeout(resolve, 800);
});
document.querySelector("#out").textContent = "Done";

You see Waiting, then Done.

Second look. The pause is this function only. The click handler is parked at await. The rest of the page is not inside this function.

<p id="out">Ready.</p>
<button id="go" type="button">Go</button>
<script>
document.querySelector("#go").addEventListener("click", async function () {
document.querySelector("#out").textContent = "Waiting";
await new Promise(function (resolve) {
  setTimeout(resolve, 800);
});
document.querySelector("#out").textContent = "Done";
});
</script>

33 Clicks still work

clicks — While one function is parked on await, another button's function can run.

document.querySelector("#status").textContent = "Waiting";
await new Promise(function (resolve) {
  setTimeout(resolve, 1500);
});
document.querySelector("#status").textContent = "Done";

You see Click Start. The line says Waiting. Click Count twice. The count is 2 while the line still says Waiting. Then the line says Done.

Second look. await is not a frozen tab. The busy loop was a frozen tab. This button is parked, and Count is a different function.

<p id="status">Ready.</p>
<p id="count">0</p>
<button id="start" type="button">Start</button>
<button id="countup" type="button">Count</button>
<script>
document.querySelector("#countup").addEventListener("click", function () {
  const n = Number(document.querySelector("#count").textContent);
  document.querySelector("#count").textContent = String(n + 1);
});
document.querySelector("#start").addEventListener("click", async function () {
  document.querySelector("#status").textContent = "Waiting";
  await new Promise(function (resolve) { setTimeout(resolve, 1500); });
  document.querySelector("#status").textContent = "Done";
});
</script>

34 await belongs inside async

async — await is legal inside an async function. On a plain function the script fails to load.

const script = document.createElement("script");
script.textContent = "function go(){ await 1; }";
document.body.appendChild(script);

You see The line names await. The function go never runs.

Second look. A syntax error fails the whole script tag. Later listeners in that same tag are never stored.

<p id="out">Ready.</p>
<button id="go" type="button">Go</button>
<script>
document.querySelector("#go").addEventListener("click", async function () {
window.onerror = function (message) {
  document.querySelector("#out").textContent = String(message);
};
const script = document.createElement("script");
script.textContent = "function go(){ await 1; }";
document.body.appendChild(script);
});
</script>

35 try and catch

try — try / catch around await is the same job as .catch. A rejection jumps to catch.

try {
  await Promise.reject(new Error("ruler"));
  document.querySelector("#out").textContent = "then";
} catch (err) {
  document.querySelector("#out").textContent = err.message;
}

You see ruler. The word then is not written.

Second look. The line under await does not run when the promise rejects. catch is the next place that runs.

<p id="out">Ready.</p>
<button id="go" type="button">Go</button>
<script>
document.querySelector("#go").addEventListener("click", async function () {
try {
  await Promise.reject(new Error("ruler"));
  document.querySelector("#out").textContent = "then";
} catch (err) {
  document.querySelector("#out").textContent = err.message;
}
});
</script>

36 The missing await

missing await — Forgetting await does not throw. You still hold the promise.

const price = Promise.resolve(50);
document.querySelector("#out").textContent = price + 1;

You see [object Promise]1.

Second look. The page looks calm. The console is not red. The bug is the missing word await.

<p id="out">Ready.</p>
<button id="go" type="button">Go</button>
<script>
document.querySelector("#go").addEventListener("click", async function () {
const price = Promise.resolve(50);
document.querySelector("#out").textContent = price + 1;
});
</script>

37 The same line with await

await — await takes the number out of the promise. Then plus is ordinary arithmetic.

const price = await Promise.resolve(50);
document.querySelector("#out").textContent = String(price + 1);

You see 51.

Second look. Same promise as the previous heading. The only added word is await.

<p id="out">Ready.</p>
<button id="wrong" type="button">Missing await</button>
<button id="right" type="button">With await</button>
<script>
document.querySelector("#wrong").addEventListener("click", async function () {
  const price = Promise.resolve(50);
  document.querySelector("#out").textContent = price + 1;
});
document.querySelector("#right").addEventListener("click", async function () {
  const price = await Promise.resolve(50);
  document.querySelector("#out").textContent = String(price + 1);
});
</script>
