This is project 1. You build it when the last digit of your roll, divided by 3, leaves a remainder of 1. Digits 1, 4, and 7.

A counter at your place. The card, the slip, and the figures are three parts of the same desk. A person writes a name and presses Find. The card shows that item and the price the computer sent. The slip keeps a row for each item the computer knew. A second Find for the same item adds one to Times on that row. It does not add a second row. Found is how many rows are on the slip. Dearest is the greatest price on the slip. Ruler clears the card and leaves the slip as it was. An empty box does not ask, and the card and the slip stay as they were. A stopped computer clears the card and leaves the slip as it was.

This is lookup.html. Your place and your header colour come from the last digit of your roll. The place name is white.

The finished lookup

lookup.html
  header     your place, your colour, the name in white
  status     id="status"     one sentence in the file
  ask        id="item"       button id="find"     Find
  card       id="card"
             id="card-name"     empty in the file
             id="card-price"    empty in the file
  slip       Item | Price | Times
             id="slip"          no rows in the file
  figures    id="found"      starts at 0
             id="dearest"    starts at 0
  footer     your roll

Topic 1 — The page

  • The page is lookup.html in f24a-YOURROLL-lab6.
  • The heading is your place. The header uses your colour. The place name is white. The footer shows your roll.
  • Commit with the message 1 The lookup — The page.

Topic 2 — The card

  • The card id is card. The name id is card-name. The price id is card-price. Both are empty in the file.
  • Commit with the message 1 The lookup — The card.

Topic 3 — The slip

  • Put a status line on the page. Its id is status. The file contains one sentence in that line.
  • The slip headings are Item, Price, and Times. The body id is slip. The file has no rows.
  • Found id is found and starts at 0. Dearest id is dearest and starts at 0.
  • Commit with the message 1 The lookup — The slip.

Topic 4 — The ask

  • The name box id is item. The button id is find. The words on it are Find.
  • Commit with the message 1 The lookup — The ask.

Topic 5 — The server file

  • Copy server.js into this folder. Do not change it.
  • Run node server.js. Open http://localhost:3016/lookup.html.
  • Commit with the message 1 The lookup — The server file.

Topic 6 — Find is stored

  • The script stores a listener on Find. The line does not call the function. Loading the page leaves the sentence, the card, and the slip as they are in the file.
  • Commit with the message 1 The lookup — Find is stored.

Topic 7 — Loading

  • Find sets the status line to Loading… and the button stops taking clicks.
  • Commit with the message 1 The lookup — Loading.

Topic 8 — The card fills

  • Find with pen in the box. The status line says pen: Rs 50. The card name is pen. The card price is 50.
  • The digits 50, 80, and 40 are not written in lookup.html. They are not written in the page script. They stay inside server.js.
  • Commit with the message 1 The lookup — The card fills.

Topic 9 — The first row

  • That same Find puts one row on the slip: pen, 50, 1. Found shows 1. Dearest shows 50.
  • Commit with the message 1 The lookup — The first row.

Topic 10 — The same item again

  • Find pen again. The slip still has one row. Times is 2. Found stays 1. Dearest stays 50. The card still shows pen and 50.
  • Commit with the message 1 The lookup — The same item again.

Topic 11 — A second item

  • Find copy. The card shows copy and 80. The slip has two rows. Found shows 2. Dearest shows 80.
  • Commit with the message 1 The lookup — A second item.

Topic 12 — A name that is not there

  • Find ruler. The status line says ruler is not in the shop. The card name and the card price are blank. The slip stays on two rows. Found stays 2. Dearest stays 80.
  • Commit with the message 1 The lookup — A name that is not there.

Topic 13 — An empty box

  • Clear the box and press Find. The status line says undefined. The page does not ask. The slip stays. The card stays blank.
  • Commit with the message 1 The lookup — An empty box.

Topic 14 — The computer is off

  • Stop node. Find with pen in the box.
  • The status line says The server is not answering. The card is blank. The slip stays on the rows it already had.
  • Commit with the message 1 The lookup — The computer is off.

Topic 15 — The button comes back

  • After a card fills, the button takes a click again.
  • After ruler, the button takes a click again.
  • After the computer is off, the button takes a click again.
  • Commit with the message 1 The lookup — The button comes back.

Topic 16 — The sentence in the file

  • Refresh brings that sentence back. The card is empty. The slip is empty. Found is 0. Dearest is 0.
  • Commit with the message 1 The lookup — The sentence in the file.
