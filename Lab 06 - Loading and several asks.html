48 The line says Loading

Loading — Write Loading… before the await. Write the price when the body arrives.

document.querySelector("#out").textContent = "Loading…";
const response = await fetch("/api/price?item=pen");
const data = await response.json();
document.querySelector("#out").textContent = data.item + ": Rs " + data.price;

You see Loading…, then pen: Rs 50.

Second look. If you write the price first and the loading text after, the loading text is what stays.

49 The button goes quiet

disabled — disabled = true stops another click while the request is out. The button paints grey.

const button = document.querySelector("#go");

You see pen: Rs 50, and the button takes a click again.

Second look. Leaving disabled true on the success path only is the bug in the next headings. A failure must enable it too.

50 finally after a success

finally — finally runs after try when the lines in try finish.

const button = document.querySelector("#go");
button.disabled = true;
try {
  const response = await fetch("/api/price?item=pen");
  const data = await response.json();
  document.querySelector("#out").textContent = data.item + ": Rs " + data.price;
} finally {
  button.disabled = false;
}

You see pen: Rs 50. The button is enabled.

Second look. The price is written in try. The button is enabled in finally. Those are two different jobs.

51 finally after a failure

  document.querySelector("#out").textContent = "The server is not answering";
} finally {
  button.disabled = false;

You see The server is not answering. The button takes a click again.

Second look. Put the enable only under the price line, and this failure leaves the button dead.

53 Three awaits in a row

in a row — await, then another await, then another. The second request starts when the first reply is in.

const names = ["pen", "copy", "tea"];
const started = Date.now();
const lines = [];
for (let i = 0; i < names.length; i++) {
  const response = await fetch("/api/price?item=" + names[i]);
  const data = await response.json();
  lines.push(data.item + " " + data.price);
}
const ms = Date.now() - started;
document.querySelector("#out").textContent = lines.join(" · ") + " · " + ms + " ms";

You see pen 50 · copy 80 · tea 40 and a time around three seconds.

Second look. Each price waits out its own 800 milliseconds. Three in a row add up.

54 Promise.all

Promise.all — Promise.all takes a list of promises and fulfils when all of them fulfil.

const names = ["pen", "copy", "tea"];
const started = Date.now();
const responses = await Promise.all(names.map(function (name) {
  return fetch("/api/price?item=" + name);
}));
const lines = [];
for (let i = 0; i < responses.length; i++) {
  const data = await responses[i].json();
  lines.push(data.item + " " + data.price);
}
const ms = Date.now() - started;
document.querySelector("#out").textContent = lines.join(" · ") + " · " + ms + " ms";

You see pen 50 · copy 80 · tea 40 and a time around one second.

Second look. The three requests are out together. The page waits for the slowest one, then reads the bodies.

55 The wait is the slowest one

slowest — Promise.all finishes when the slower promise finishes, not when the faster one does, and not at the sum.

const started = Date.now();
await Promise.all([
  new Promise(function (resolve) { setTimeout(resolve, 200); }),
  new Promise(function (resolve) { setTimeout(resolve, 700); })
]);
document.querySelector("#out").textContent = String(Date.now() - started) + " ms";

You see A time near 700 ms, not near 900 ms.

Second look. The 200 millisecond timer is done and waiting. all cannot finish until the 700 millisecond timer finishes.

56 allSettled keeps every result

allSettled — Promise.allSettled waits for every promise, including one that rejects. Each result has a status.

const good = Promise.resolve(50);
const missing = Promise.reject(new Error("ruler"));
const other = Promise.resolve(40);
const rows = await Promise.allSettled([good, missing, other]);
document.querySelector("#out").textContent = rows.map(function (row) {
  if (row.status === "fulfilled") return row.status + " " + row.value;
  return row.status + " " + row.reason.message;
}).join(" · ");

You see fulfilled 50 · rejected ruler · fulfilled 40.

Second look. The rejection of ruler does not throw away 50 and 40. You still have to read each status.

57 Promise.all stops at the first failure

Promise.all — Promise.all rejects as soon as one promise rejects. catch receives that error. The other values are not passed to then.

Promise.all([
  Promise.resolve(50),
  Promise.reject(new Error("ruler")),
  Promise.resolve(40)
]).then(function () {
  document.querySelector("#out").textContent = "then";
}).catch(function (err) {
  document.querySelector("#out").textContent = err.message;
});

You see ruler. The word then is not written.

Second look. fetch fulfils on 404, so Promise.all of three fetches still fulfils when one item is missing. A throw inside the mapper is what rejects all.

58 POST

POST — The second argument of fetch sets the method. POST sends a body. GET does not.

const response = await fetch("/api/orders", {
  method: "POST",
  headers: { "Content-Type": "application/json" },
  body: JSON.stringify({ item: "pen", qty: 2 })
});
document.querySelector("#out").textContent = String(response.status);

You see 201.

62 The whole ask

together — One async function writes Loading…, checks ok, reads the body, and catch writes the silence.

const status = document.querySelector("#out");
status.textContent = "Loading…";
try {
  const response = await fetch("/api/price?item=pen");
  if (!response.ok) {
    status.textContent = "pen is not in the shop";
    return;
  }
  const data = await response.json();
  status.textContent = data.item + ": Rs " + data.price;
} catch (err) {
  status.textContent = "The server is not answering";
}

You see Pen shows pen: Rs 50. Ruler shows ruler is not in the shop.

Second look. This file is the teaching example. The three projects are not this file.

<p id="out">Ready.</p>
<button id="pen" type="button">Pen</button>
<button id="ruler" type="button">Ruler</button>
<script>
async function load(item) {
  const status = document.querySelector("#out");
  status.textContent = "Loading…";
  try {
    const response = await fetch("/api/price?item=" + item);
    if (!response.ok) {
      status.textContent = item + " is not in the shop";
      return;
    }
    const data = await response.json();
    status.textContent = data.item + ": Rs " + data.price;
  } catch (err) {
    status.textContent = "The server is not answering";
  }
}
document.querySelector("#pen").addEventListener("click", function () { load("pen"); });
document.querySelector("#ruler").addEventListener("click", function () { load("ruler"); });
</script>
