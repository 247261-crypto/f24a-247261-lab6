This is project 0. You build it when the last digit of your roll, divided by 3, leaves a remainder of 0. Digits 0, 3, 6, and 9.

Morning. The counter at your place has a board and a till. Three cards are already on the board: pen, copy, and tea. Their prices are empty. The person at the counter presses Load the shelf. The page asks for the three prices in one wait. Each card shows the price the computer sent. Loaded becomes 3. Dearest becomes the greatest of those prices. Sum becomes the three prices added. A stopped computer blanks the three prices and sets Loaded, Dearest, and Sum back to 0.

This is shelf.html. Your place and your header colour come from the last digit of your roll. The place name is white.

The finished shelf

shelf.html
  header     your place, your colour, the name in white
  status     id="status"     one sentence in the file
  board      id="board"
             card pen     id="pen"      empty in the file
             card copy    id="copy"     empty in the file
             card tea     id="tea"      empty in the file
  till       id="loaded"     starts at 0
             id="dearest"    starts at 0
             id="sum"        starts at 0
  button     id="load"       Load the shelf
  footer     your roll

Topic 1 — The page

  • The page is shelf.html in f24a-YOURROLL-lab6.
  • The heading is your place. The header uses your colour. The place name is white. The footer shows your roll.
  • Commit with the message 0 The shelf — The page.

Topic 2 — The board

  • Put a status line on the page. Its id is status. The file contains one sentence in that line.
  • The board id is board. Three cards sit on it, named pen, copy, and tea. The price ids are pen, copy, and tea. Each price is empty in the file.
  • Commit with the message 0 The shelf — The board.

Topic 3 — The till

  • Loaded id is loaded and starts at 0. Dearest id is dearest and starts at 0. Sum id is sum and starts at 0.
  • Commit with the message 0 The shelf — The till.

Topic 4 — The server file

  • Copy server.js into this folder. Do not change it.
  • Run node server.js. Open http://localhost:3016/shelf.html.
  • Commit with the message 0 The shelf — The server file.

Topic 5 — The button is stored

  • The button id is load. The words on it are Load the shelf.
  • The script stores a listener on that button. The line does not call the function. Loading the page leaves the prices empty and the till at 0.
  • Commit with the message 0 The shelf — The button is stored.

Topic 6 — Loading

  • The click sets the status line to Loading… and the button stops taking clicks.
  • Commit with the message 0 The shelf — Loading.

Topic 7 — Three asks in one wait

  • The click asks for pen, copy, and tea in the same moment. The three prices appear after one wait.
  • Commit with the message 0 The shelf — Three asks in one wait.

Topic 8 — The cards and the till

  • After that wait the cards show pen 50, copy 80, and tea 40. Loaded shows 3. Dearest shows 80. Sum shows 170.
  • The digits 50, 80, 40, and 170 are not written in shelf.html. They are not written in the page script. The prices stay inside server.js. Sum and Dearest are worked out from the replies.
  • Commit with the message 0 The shelf — The cards and the till.

Topic 9 — The computer is off

  • Stop node. Click Load the shelf.
  • The status line says The server is not answering. The three prices are blank. Loaded, Dearest, and Sum show 0.
  • Commit with the message 0 The shelf — The computer is off.

Topic 10 — The button comes back

  • After the cards fill, the button takes a click again.
  • After the computer is off, the button takes a click again.
  • Commit with the message 0 The shelf — The button comes back.

Topic 11 — The sentence in the file

  • Refresh brings that sentence back. The three prices are empty. Loaded, Dearest, and Sum are 0.
  • Commit with the message 0 The shelf — The sentence in the file.
